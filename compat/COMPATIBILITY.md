# Compatibility

What compiles. Generated by `compat/generate.mjs` from `compat/react.surface.json`
and scriptc's `surface-manifest.json`; run `--check` to fail on drift.

There is no React runtime and no Node runtime in a built binary. These are
source-level surfaces: your code is compiled against implementations in
`compat/` and scriptc's lowerings. Anything below marked unsupported is a
compile error, not a runtime failure.

## JSX

| | status | |
|---|---|---|
| `host elements` | yes | <div>, <button>, ... |
| `component elements` | yes | <Counter /> calls the function once and owns its effects until removal |
| `attributes` | yes | string literals are set once; other expressions become reactive |
| `event handlers` | yes | onclick -> click; any on* prop whose value is a function |
| `text children` | yes |  |
| `expression children` | yes | auto-wrapped into a reactive binding and coerced to string |
| `props on components` | yes | a plain object argument; children arrive as props.children |
| `fragments` | yes | <>...</> returns multiple root nodes without a wrapper element |
| `spread props` | yes | source-order last-write-wins; function-valued non-event host props are reactive getters |
| `array / .map() children` | yes | an inline .map() with a key prop lowers to a keyed each() |
| `element-valued expression children` | yes | typed El expressions are inserted directly; mixed element/primitive unions are refused |
